# Focus mode

*Settings → Focus.* One switch that combines Do Not Disturb, app blocking and the calendar.

* **Start it:** for 25/45/60/90 minutes, until you stop it, or as a Pomodoro cycle
  (work/break lengths configurable, no break after the last block).
* **From the calendar:** any event whose title contains a keyword (default
  `focus`, `deep work`, `🎯`) or whose description contains `#focus` is a focus
  block — recurring events, all-day events and blocks that cross midnight work.
* **While it's on:** Do Not Disturb is switched on (urgent notifications may break
  through) and apps on your block list can't be launched — it uses the same gate as
  Parental Controls. Your previous DND setting is restored afterwards unless you
  changed it yourself meanwhile. Settings is never blockable.
* **With Parental Controls:** Focus never changes them. With **Strict** on and a
  Parental Controls PIN set, ending a manual or Pomodoro session early asks for that
  PIN — so a homework block can't simply be cancelled.
